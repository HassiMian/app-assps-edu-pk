# ASSPS official teacher marks preview and assessment offerings (review only)

The official school grade settings are A+90-100 A80-89 B70-79 C60-69 D40-59 F0-39.
The former teacher preview used 33 percent passing and obsolete E grades.
The new helper reads authenticated school grade settings and shows no grade if unavailable.
The teacher screen requests the authorized subject offering catalog for assessments.
Assessment 1-4 have zero approved offerings, so assessment Save Marks must remain disabled.
The UI intersects genuinely approved class/section subject offerings with teacher assignments.
It never invents Principal approvals or modifies stored First Term student results.
The source patch is against actual deployed Connect source; it is not a live frontend deployment.
Standard renderer source provenance and real signed-in Teacher and Principal UI acceptance remain required.
