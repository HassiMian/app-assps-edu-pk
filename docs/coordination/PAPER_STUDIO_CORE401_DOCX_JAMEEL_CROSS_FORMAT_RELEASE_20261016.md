Explicitly reproduced **fail-before** with a real generated binary DOCX. Fixed only suffix formatter: missing/boolean/blank values generate no mark label; a real numeric `0` or nonblank numeric string zero still explicitly prints `[0]`. The 213 real saved student numeric zero examination marks are a distinct protected dataset and are never reinterpreted by this paper exporter fix.
