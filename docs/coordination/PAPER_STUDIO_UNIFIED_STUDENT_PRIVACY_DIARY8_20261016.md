The new release-snapshot test **failed before** (`Student-visible answer alias leaked: PRIVATE_ANSWER_TEXT`, existing eight cases pass, new ninth case fails). This proves a *source-level risk*, not a confirmed leak from any actual school print job.

Narrow backend fix: exact known sensitive alias denylist with case/underscore/hyphen-insensitive canonicalization, recursive over nested MCQ options. Student printable fields like question prompt, option text, roll number, class and `answerLines` retained; authorized staff projection still contains original answer key and source release JSON remains unchanged. No grade/mark computation, tenant-RLS semantics, HTML rendering, official papers or stored records changed. Exactly one backend service and one backend test changed; extra source-only Playwright harness change prevents an unmocked Question Bank API from falsely navigating the fake JWT browser fixture to `/login`, instead of calling live school APIs.
