## Implementation
PaperEditor/core/PaperVisualEvidenceManifest.js creates assps-native-paper-visual-evidence-manifest v1. Requires previously verified baseline JSON, exact matching user-selected school/paper/family, source revision/overlay state, cropped ORIGINAL preview PNG and native Print/Save as PDF, six explicit self-attested manual review checks and separate retained files. Computes SHA-256 of baseline envelope/source/native state, actual PNG bytes, actual PDF bytes and the resulting manifest JSON. All evidence files stay local: the manifest stores only fingerprints, original filenames, dimensions/sizes, native renderer and status. It is NOT an encrypted archival package, server signature, independent source-to-image semantic verifier, release approval or PDF replacement.
- PNG validation: actual eight-byte PNG magic, IHDR + IEND structure, 650x850 minimum, up to 30 MP/24 MB and native A4-height geometry. Early Years can present one continuous 794x2232 canvas spanning TWO A4 heights. Accepts 1–4 continuous A4-height spans instead of cropping/editing the existing teacher sheet. Browser also decodes the chosen PNG with createImageBitmap AFTER checking pixel-memory bounds. A file extension alone is not proof.
- PDF validation: actual %PDF- and %%EOF within last 2048 bytes, max 24 MB. Reads plainly declared MediaBox page dimensions if available and blocks explicitly non-A4 boxes. A PDF whose page geometry cannot be reliably extracted is labelled PAGE_GEOMETRY_NOT_MACHINE_VERIFIED, not silently approved. No independent page-to-page content matching is claimed.
- Manual checks are SELF_ATTESTED_NOT_INDEPENDENTLY_VERIFIED. Manifest always records approvalStatus=EVIDENCE_COLLECTED_UNVERIFIED, actualVisualDifferenceEvaluation=PENDING_INDEPENDENT_REVIEW, serverSignaturePresent=false, sourceMutationAllowed=false, currentProductionCutoverAllowed=false. Forged/relabelled approved status is rejected even if an unsigned checksum is recomputed.
- verifyVisualEvidenceManifest requires the same original baseline JSON AND both original PNG/PDF bytes. Changed bytes, native source, tenant, family, file geometry, source revision or manifest content fail closed. A manifest alone cannot recreate/verify missing original evidence.
- VisualEvidenceManifestDialog.jsx is shared by BOTH existing read-only baseline dialogs. It performs the BASELINE-vs-actual-current-saved-record/overlay/template compare before AND after async evidence reading to catch stale browser state. No HTTP upload, no auto screenshot, no localStorage mutation, no source restore, no server database call, no renderer cutover. Separate optional Verify action reopens manifest and validates all three original files again.
