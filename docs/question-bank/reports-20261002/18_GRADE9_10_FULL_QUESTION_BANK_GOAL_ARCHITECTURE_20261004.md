# Grade IX-X Full Question Bank Completion Goal — Architecture Lock

Date: 2026-10-04
Parent: `b0def3d95647f33dc10d137a6298ca7bcae6a4dc`

## Mission
Build one source-traceable, board-pattern-aware, dual-medium capable Grade IX-X Question Bank instead of manually seeding isolated papers. Existing Biology IX work and Urdu-language convention remain authoritative checkpoints and are not restarted.

## Non-negotiable separation
- **Full textbook coverage is the bank default.** ALP/smart syllabus is an optional exam-year filter only.
- **Board pattern controls assessment shape, not what concepts exist in the bank.**
- A board-appearance tag requires a verified board paper artifact; third-party guess/pairing pages cannot certify it.
- Grade X 2026-27 books must not inherit 2026 old-edition paper claims as if they were new-edition 2027 evidence.
- Language-style review never grants academic approval.
- Original questions are authored from verified concepts; textbook/past-paper passages are not copied into the bank.

## Official pattern baseline
- PECTAA notification dated 07-Nov-2025 formally notified the Revised Grade-9 ALP, pairing schemes and model papers for Annual Examination 2026 across Punjab. We use its pairing/model-paper evidence for Grade IX assessment shape while preserving full-book bank coverage.
- Official BISE Lahore Science Group scheme confirms IX/X subject structure and marks, including IX Islamiyat, X Pakistan Studies, Math 75 each grade, and Physics/Chemistry/Biology or Computer theory/practical structure.
- The current Grade X 2026-27 textbook cohort needs its own official 2027 model/pairing evidence when published; until then the pattern-specific release gate stays pending rather than guessed.

## Data pipeline
Official source/edition → verified chapter/topic/grammar index → coverage audit → original question authoring → bilingual/grammar checks → answer/rubric checks → duplicate audit → board-pattern metadata → release audit → Paper Generator adapter/import.

## Completion means
Every in-scope subject has a verified source edition, topic/grammar coverage with no required gaps, board-pattern mapping or an explicit official-unpublished state, original MCQ/short/long/grammar corpus as applicable, reviewed answers/rubrics, dual-medium parity where supported, duplicate checks, release validation, full regression and a verified GitHub remote commit. Production writes remain separately authorized.
